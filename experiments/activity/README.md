# 本地活动测试资料

保留独立活动测试的Java影子服务、活动目录与生成代码。它包含此前本地展示的活动入口、商店、排行榜等内容，用户要求先保存数据，不加入当前在线活动。

本目录的 `LocalSave`、`StandaloneServer` 等同名文件属于活动影子版本，不能覆盖稳定服务的同名源码。独立实验使用 `labActivity` 命名空间；50层奖励和排行有本地恢复规则，原Buff和全部多人规则尚不完整。

`prepare_lab_server.py` 保存此前候选构建的处理关系，仍引用外部原始资料与原工程路径。生成清单不是玩家数据。安装包、活动存档、签名凭据和实机截图未复制。

后续恢复应先检查活动自身规则和依赖，再构建独立测试应用。本次仅保存源码和数据，没有开启在线活动。
