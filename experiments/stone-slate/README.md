# 未发布石板玩法草稿

共享开发源中曾保留石板玩法接线，但它没有进入本次整理所对应的稳定在线二进制。直接全量编译共享源会意外带入草稿，因此审阅稿将它单独存放。

- `src`：`StoneSlateBattle.java` 草稿。
- `tests`：引用草稿的自测源码。
- `LocalSave.integration.patch`：从稳定 `LocalSave` 恢复共享开发源接线的差异，仅供继续开发和审阅。
- 基础石板布局数据仍保留在稳定服务 `resources/stone_slate_catalog.json`，用于来源与布局一致性核对；存在数据不代表玩法已开启。

默认Java构建不引用本目录。若以后恢复石板，需把相关源码、资源与接线作为独立变更审阅，完成完整结算与并发回归后再决定合入。
