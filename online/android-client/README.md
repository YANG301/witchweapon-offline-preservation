# Android桥接与补丁工具

本目录整理当前Android桥接源码、Lua修复和历次资源/构建工具，保留原层级及互相导入关系。

| 路径 | 用途 |
| --- | --- |
| `src` | 在线认证桥接、资源更新、原版UI连接、聊天和记住登录等Java实现 |
| `baseline_sources` | 历史构建的固定桥接基线 |
| `lua` | 客户端运行时修复与接口同步 |
| `draw-bridge` | 抽卡桥接补充 |
| `patch_*.py` | Lua、配置、预制体和桥接源码转换 |
| `build_*.py` | 固定输入版本的历次候选/整合构建，不是全部可独立运行的入口 |
| `tests` | 针对桥接、资源处理和Lua修复的测试源码 |

已有完整APK基线为v125，历史入口是 `build_startup_version_v125_apk.py`。其跨项目导入源码已收录在根 `local-mode`，但脚本仍指向原工程路径。重新构建还需要v124APK、补丁191的签名完整覆盖集、原验收输入和签名环境。

不执行整目录构建，不因缺少输入就跳过原哈希校验。先阅读根目录的 [构建](../../docs/BUILD.md) 和 [外部输入](../../docs/INPUTS.md)。本次没有把“启动检查耗时拆分”待办伪装成已修复代码。
