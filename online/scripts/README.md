# 构建与历史整合脚本

常规Go构建入口是 `Build.ps1`，其工具与缓存位置由 `GoEnvironment.ps1` 配置。`StartServer.ps1` 只启动小型Go服务，不代表自动启动完整Java、聊天和资源更新链。

`build_*.py`、`release_*.py`、`sync_*.py` 保留历次源码变换、候选生成和本地服务同步过程。有的依赖固定JAR/APK、原验收记录，或引用原工程中的部署模块。公开稿没有复制生产运营模块和验收数据，因此它们是追溯代码，不是本轮整理后的统一发布入口。

这些历史工具还含原工程绝对路径，直接执行可能在原工程位置写入产物或同步本地程序。审阅时只读代码；实际构建先选择明确入口、隔离输出并准备匹配输入，不批量执行本目录。

Java稳定完整构建见 `../legacy-server/Build.ps1`，安卓输入边界见根 [构建说明](../../docs/BUILD.md)。
